CBSE 2027 Study Planner - Android setup

This is a small installable web app (PWA). The app files need to be hosted on an HTTPS website before Chrome can install it as a true home-screen app with offline caching.

Quick local use:
1. Extract the ZIP.
2. Open index.html in a browser to use the checklist. Progress is stored in that browser on that device.

Install on Android (recommended):
1. Upload the contents of this folder to an HTTPS static host (for example GitHub Pages or Netlify).
2. Open the resulting HTTPS website in Chrome on your Android phone.
3. Tap Chrome menu (three dots) > Install app or Add to Home screen.
4. Open the installed app. Your daily ticks and chapter progress are saved in that browser's local storage.
5. Use Progress > Export backup regularly. Import the JSON backup if you move browsers/devices.

The app does not send your study data to a server. It is not an APK and cannot be remotely installed by this chat.
